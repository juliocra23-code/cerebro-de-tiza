Política de privacidad

Última actualización: 21 de noviembre de 2026

"Monigote YouTube" es una herramienta de uso personal para gestionar el canal de YouTube "Cerebro de Tiza". Solo la usa su propietario.

Qué datos usa

Con la autorización del propietario, la herramienta accede mediante la API de YouTube a los datos de su propio canal: información del canal, videos, estadísticas y la posibilidad de subir y editar videos.

Cómo se guardan

Las credenciales de acceso (token) se guardan únicamente en el ordenador del propietario. No se envían a ningún servidor propio ni de terceros, y no se venden, comparten ni publican.

Servicios de API de YouTube

El uso de la información recibida de las API de Google cumple la Política de Datos del Usuario de los Servicios de las API de Google, incluidos los requisitos de Uso Limitado. Al usar esta herramienta también se aceptan las Condiciones del Servicio de YouTube y la Política de Privacidad de Google.

Cómo revocar el acceso

Puedes revocar el acceso en cualquier momento desde myaccount.google.com/permissions.
